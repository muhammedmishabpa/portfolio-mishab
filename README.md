# Muhammed Mishab P A — Developer Portfolio

A responsive, mobile-first personal portfolio built with plain HTML, CSS and JavaScript.

🔗 **Live site:** [portfolio-mishab.vercel.app](https://portfolio-mishab.vercel.app)

---

## About

I'm a frontend developer currently pursuing my BCA at Primus School of Management Studies. I enjoy building responsive, user-friendly websites, and I'm growing my skills in Python and SQL. This portfolio introduces who I am, my experience and education, and a few projects I've worked on.

## Features

- **Responsive, mobile-first layout** that works on phones, tablets and desktops
- **Mobile navigation menu** with an accessible toggle button
- **Accessibility built in:** skip-to-content link, semantic sections, ARIA labels
- **Experience & education timeline** with my internship and studies
- **Certifications** section
- **Selected projects** with links to their source code
- **Downloadable CV** (PDF)
- **Auto-updating footer year** using JavaScript
